## Installation

1. Clone the repository and navigate to the project directory
2. Install dependencies:
```bash
pip install -r requirements.txt
```

3. Install the CLI tool:
```bash
pip install -e .
```

## Setup

```bash
export ANTHROPIC_API_KEY="your-api-key-here"
```
